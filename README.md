# rcss2d-viewer

Replay e análise de partidas da RoboCup Soccer Simulation 2D a partir de um `.rcg`, direto no navegador. Publicado em https://rcssmonitor.barreto.sh.

Feito sobre o `web-project-template` (Bun, Vite, React 19, TanStack Router, shadcn/ui). Regras de trabalho no `AGENTS.md`.

```bash
bun install
bun run dev
```
